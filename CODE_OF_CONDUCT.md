# Código de conducta / Code of Conduct

[Español](#español) · [English](#english)

## Español

Este proyecto busca un espacio respetuoso y útil para quien contribuya, sin
importar su experiencia, origen, identidad o forma de hablar.

- Trata a las demás personas con respeto; critica el código y las ideas, no a
  quien las propone.
- Sé claro y paciente al explicar; asume buena fe.
- No se toleran el acoso, los insultos, la discriminación ni la publicación de
  datos privados ajenos.
- Las contribuciones pueden estar en español o en inglés.

Quien mantiene el proyecto puede editar, ocultar o rechazar comentarios,
commits y issues que incumplan estas normas, y bloquear a quienes lo hagan de
forma reiterada. Para reportar una conducta inadecuada, contacta con
[@AvilaCarlosDev](https://github.com/AvilaCarlosDev) mediante un aviso privado
de GitHub.

## English

This project aims to be a respectful and helpful space for everyone who
contributes, regardless of experience, background, identity or language.

- Treat others with respect; criticize code and ideas, not the people who
  propose them.
- Be clear and patient when explaining; assume good faith.
- Harassment, insults, discrimination and publishing other people's private
  data are not tolerated.
- Contributions may be written in Spanish or English.

The maintainer may edit, hide or reject comments, commits and issues that
violate these rules, and block repeat offenders. To report inappropriate
conduct, contact [@AvilaCarlosDev](https://github.com/AvilaCarlosDev) through a
private GitHub advisory.
